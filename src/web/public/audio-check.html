Полный экран — последний звонок: Нет данных.

Проверка выбора динамика через Web Audio: Проверка не загружена. Обновите страницу.

Это проверка браузерного API, через который Chrome может выбирать аудиовыход. Использование внутреннего драйвера AAudio браузер странице не сообщает.

Завершите звонок перед проверкой. Два теста играют один и тот же короткий звук с одинаковым уровнем. Начните с телефона на расстоянии от уха.

Нажмите кнопку и сравните громкость и динамик.

Если разговорного динамика нет в списке, страница не может выбрать его этим способом.

Этот тест временно включает микрофон, чтобы проверить, меняет ли режим звонка громкость или динамик. Звук с микрофона не записывается и не передаётся. После теста микрофон выключится.
